Anton Vampire

Полный справочник: установка, интерфейс, все 13 вкладок, VampireOS, технический разбор powercfg для кастомных планов, игровой режим 2.0, менеджер служб, 100+ тем, 8 CSS-стилей, настройки, безопасность, курсоры, обои и сборщики.

Начало

Введение

Anton Vampire — полностью переписанный на Electron Windows оптимизатор. Наследник All Tweaker (Python/tkinter) с сохранением концепции: запуск .bat/.cmd/.ps1/.exe/ .reg/.pow твиков через удобный UI.

Внутри — 1000+ твиков, сгруппированных по 13 вкладкам, 100+ тем в 12 группах, 8 CSS-стилей (включая Cyberpunk 2077), аудит безопасности, управление автозагрузкой, менеджер служб, VampireOS, курсоры, обои, HTML-отчёты и сборщики JSON-данных.

Powercfg · 1

Архитектура скрипта

Скрипт написан на Batch и использует powercfg.exe. Каждый блок, создающий план, следует единому шаблону:

  1. Проверка существования: powercfg /list | findstr /i "%GUID%" >nul + if not errorlevel 1 — предотвращает повторное создание.
  2. Создание (дублирование): powercfg /duplicatescheme <базовый_GUID> %GUID% — клонирует один из трёх стандартных планов: «Сбалансированный» (381b4222-...), «Высокая производительность» (8c5e7fda-...), «Экономия энергии» (a1841308-...).
  3. Переименование: powercfg /changename %GUID% "Имя" "Описание".
  4. Настройка параметров: powercfg /setacvalueindex (AC) и /setdcvalueindex (DC).

Подавление >nul убирает техвывод. 2>&1 — страховка от неподдерживаемых параметров (виртуалки, старое железо).

ℹ
AC — питание от сети. DC — от батареи. Windows хранит два набора значений для каждой схемы, поэтому в BAT-файлах почти всегда дублируются AC/DC-вызовы. На десктопе DC-значения не применяются, на ноутбуке — критичны.

Назначение: повседневная работа с небольшим смещением в сторону отзывчивости.

3.2. Maximum Performance

База: 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c (Высокая производительность).

ПараметрACDCЭффект

3.3. Power Saving

База: a1841308-3541-4fab-bc81-f71556f20b4a (Экономия энергии).

ПараметрACDCЭффект

3.4. NFS Racing

База: Высокая производительность.

ПараметрACDCЧто делает

Итог: «зажимает» CPU в состояние максимальной готовности. Ровный фреймтайм, но выше нагрев и расход.

3.5. Shooter Low-Latency

Наследует NFS Racing и добавляет:

Итог: отзывчивее в пиковых нагрузках. Теоретически ниже задержка между действием и реакцией.

3.6. Minimal Input Lag

Наследует Shooter Low-Latency и добавляет:

ПараметрACDCЧто делает
IDLEDISABLE11Полный запрет C-states. Ядра всегда в C0.

Итог: самый агрессивный профиль по отклику. Только для десктопов с хорошим охлаждением. На ноутбуках — быстрый разряд и нагрев.

Powercfg · 5

Важные замечания и предостережения

  1. Скрытые параметры. Многие GUID (PERFEPP, IDLEDISABLE, PERFBOOSTMODE) по умолчанию скрыты в GUI «Электропитание». powercfg меняет их напрямую, но после создания плана они не будут видны в настройках без правки реестра.
  2. Аппаратная зависимость. Эффект от PERFEPP, PERFBOOSTMODE, PERFDISTRIBUTETYPE зависит от архитектуры CPU (Intel Speed Shift, AMD CPPC) и прошивки (BIOS/UEFI). На старом оборудовании команды могут быть проигнорированы.
  3. Риски перегрева и нестабильности. Планы Minimal Input Lag, Energetic Death и Power Killer отключают энергосбережение. На ноутбуках и ПК с недостаточным охлаждением — троттлинг по температуре, нестабильная работа, сокращение срока службы.
  4. Отсутствие автоматического применения. Скрипт создаёт планы, но не активирует их. Для использования выберите план вручную или командой powercfg /setactive <GUID>.
  5. Идемпотентность. Повторный запуск не создаёт дубликатов, но и не обновляет настройки уже существующего плана, если они были изменены вручную.

FAQ

Нужен ли Python?

Только для сборщиков JSON через Настройки → Утилиты.

Где хранятся настройки?

В extreme_data/settings.json.

Можно ли откатить VampireOS?

Частично. Defender и OneDrive — необратимы. Для остальных — кнопка ↺ рядом с «Убить KCAS и Xeon» или «Режим Деда».

Как добавить свой твик?

  1. Положите файл в tweaks/<button>/<tab>/
  2. Добавьте описание в tweaks/descriptions.txt
  3. Запустите build_all_tabs.py

Как сменить CSS-стиль?

Настройки → Внешний вид → Стиль оформления.

Troubleshooting

Приложение не запускается

  • Запустите от администратора
  • Включите logs_enabled → extreme_data/logs/

Антивирус ругается

Нет подписи, меняет реестр, использует NSudoLG.exe. Добавьте папку в исключения.

Твик зависает

  • Увеличьте таймаут в настройках
  • Смените режим запуска

Кракозябры в логе

Пересохраните .bat в UTF-8.

План не активируется

  • 📥 Импортировать → ⚡ Активировать
  • Если план уже есть — дубликат не создаётся

Службы не восстанавливаются

  • Проверьте Services_Backup.reg
  • Fallback Start=3

Курсоры не применяются

  • Проверьте .cur / .ani
  • Папка C:\Windows\Cursors\<name>\
  • Сброс через «🗑️ Удалить все»
