🩸 Документация · v1.1.0

Anton Vampire

Полный справочник по приложению: установка, интерфейс, все 13 вкладок, VampireOS, игровой режим 2.0, менеджер служб, 100+ тем, 8 CSS-стилей, настройки, безопасность, курсоры, обои и сборщики.

Начало

Введение

Anton Vampire — полностью переписанный на Electron Windows оптимизатор. Наследник All Tweaker (Python/tkinter) с сохранением концепции: запуск .bat/.cmd/.ps1/.exe/ .reg/.pow твиков через удобный UI.

Внутри — 1000+ твиков, сгруппированных по 13 вкладкам, 100+ тем в 12 группах, 8 CSS-стилей (включая Cyberpunk 2077), аудит безопасности, управление автозагрузкой, менеджер служб, VampireOS, курсоры, обои, HTML-отчёты и сборщики JSON-данных.

Open Source

CC BY-NC-SA 4.0, весь код на GitHub.

Portable

Всё в extreme_data/ рядом с exe.

Без зависимостей

Electron + Node.js уже в бандле.

Windows 10/11

Только Windows, x64.

⚠
Требуются права администратора. Приложение проверяет fltmc при старте и предлагает перезапуск с UAC через Start-Process -Verb RunAs.

Установка

Установка

Способ 1: одной командой

Откройте Win + R → cmd и вставьте:

curl -g -k -L -# -o "%temp%\AntonVampire.Setup.exe" "https://github.com/ZikaSVG/Anton-Vampire/releases/download/v1.1.0/Anton.Vampire.Setup.1.1.0.exe" && start "" "%temp%\AntonVampire.Setup.exe"

Способ 2: Setup вручную

  1. Скачайте Anton.Vampire.Setup.1.1.0.exe
  2. Запустите — UAC запросит подтверждение
  3. Следуйте инструкциям установщика NSIS

Способ 3: Portable

Скачайте Anton.Vampire.Portable.rar, распакуйте в любую папку и запустите AntonVampire.exe. Все данные лягут в extreme_data/ рядом с exe.

Способ 4: из исходников

git clone https://github.com/ZikaSVG/Anton-Vampire.git
cd Anton-Vampire
npm install
npm start
✓
Проверка: после запуска откройте Настройки → О программе — там будет версия и кнопка «↺ Сбросить все настройки».
UI

Интерфейс

Приложение состоит из 5 постоянных элементов:

  1. Сайдбар — разворачивается по hover, 13 разделов
  2. Топбар — драг-зона окна, поиск, кнопки
  3. Табы — под-вкладки внутри раздела
  4. Content — содержимое активной вкладки
  5. Статус-бар — статус и счётчик выбранных

Сайдбар

В свёрнутом виде — только иконки (--sidebar-collapsed: 60px). При hover разворачивается до --sidebar-expanded: 216px за 250ms.

Топбар

  • Лого + версия
  • Глобальный поиск #global-search
  • Кнопки: Выделить всё, ▶ Выполнить, ♻ Обновить, ⛶ Fullscreen

Отдельная вкладка для глобальной оптимизации системы. Один основной BAT-файл GameMode/VampireOS.bat и два вспомогательных для питания.

Режимы чекбоксов

Параметр checkbox_display_mode:

  • launcher — через launcher.exe
  • powerrun — через PowerRun.exe (наивысшие привилегии)
  • nsudolg — через NSudoLG.exe (TrustedInstaller, по умолчанию)
  • minsudo — через MinSudo.exe (TrustedInstaller)
  • cmd — через cmd.exe /c

Патчинг .bat

  • Вырезаются pause / timeout / choice
  • start → start /b "" — без окна консоли

Стрим вывода

Авто-декодинг UTF-8 → fallback на cp866. Если кракозябры — пересохраните .bat в UTF-8.

Таймаут

По умолчанию tweak_timeout_ms: 300000 (5 минут). Настраивается в Настройки → Интерфейс.

Механика

Источники и пары

Твики рендерятся через универсальный sources.js:

  • renderSources(host, sources[]) — строит панель источников
  • loadSourceData(src) — читает JSON + сканирует диск
  • buildPairMap(files, cancels) — сопоставляет твик ↔ отмена
  • coreName(filename) — выделяет ядро имени без расширения

Пара определяется по совпадению coreName(). Кнопка ↩ появляется рядом с твиком, если найдена отмена.

Механика

Preload и lazy

  • lazy_tabs: true — вкладка рендерится только при переходе
  • preload_heavy_tabs: false — тяжёлые данные (startup, apps, audits) не грузятся при старте
  • preload_audits: false — аудит безопасности не запускается автоматически
  • security_auto_audit: true — автоаудит при открытии вкладки Безопасность
  • show_splash: true — splash-screen с прогрессом

FAQ

Нужен ли Python?

Только если вы собираете JSON-данные через Настройки → Утилиты. Для обычной работы — нет, всё в бандле Electron.

Где хранятся настройки?

В extreme_data/settings.json рядом с exe (portable).

Можно ли откатить VampireOS?

Частично. Некоторые изменения (например, удаление Defender или OneDrive) необратимы. Для остальных используйте кнопку ↺ рядом с «Убить KCAS и Xeon» или «Режим Деда». Всегда делайте точку восстановления до запуска.

Как добавить свой твик?

  1. Положите .bat / .ps1 / .exe / .reg / .pow в нужную папку tweaks/<button>/<tab>/
  2. Добавьте описание в tweaks/descriptions.txt (формат filename.bat=Описание)
  3. Откройте Настройки → Утилиты → build_all_tabs.py → ▶ Запустить
  4. Готово — твик появится во вкладке

Как сменить CSS-стиль?

Настройки → Внешний вид → Стиль оформления. Доступно 8 вариантов, включая Cyberpunk 2077.

Troubleshooting

Приложение не запускается

  • Запустите от имени администратора
  • Если UAC отменён — приложение закроется. Нажмите «Перезапустить» в диалоге
  • Включите logs_enabled и посмотрите extreme_data/logs/

Антивирус ругается

Три причины:

  1. Нет цифровой подписи (сертификат $300–500/год)
  2. Меняет реестр / службы / системные файлы
  3. Использует NSudoLG.exe, PowerRun.exe, MinSudo.exe, cmd.exe

→ Добавьте папку в исключения. Код открыт — можно проверить каждую строчку.

Твик зависает

  • По умолчанию таймаут 5 минут. Увеличьте в Настройки → Интерфейс
  • Смените режим: nsudolg → powerrun → minsudo → cmd
  • Добавьте папку в исключения антивируса

Кракозябры в логе

Твик выводит в OEM-кодировке (cp866). Приложение пытается декодировать UTF-8, при ошибке — fallback на cp866. Если кракозябры всё равно — пересохраните .bat в UTF-8.

VampireOS не запускается

  • Убедитесь, что вы на стационарном ПК (для «Убить KCAS и Xeon»)
  • Создайте точку восстановления до запуска
  • Проверьте наличие GameMode/VampireOS.bat в tweaks/
  • Отключите антивирус на время запуска

План электропитания не активируется

  • Сначала нажмите 📥 Импортировать план
  • Затем — ⚡ Активировать план
  • Если план уже есть в системе — дубликат не создаётся, активация пройдёт сразу

Службы не восстанавливаются из бэкапа

  • Проверьте наличие Services_Backup.reg в папке tweaks/Службы/
  • Если файла нет — приложение применит безопасный сброс Start=3
  • Создайте бэкап заново через 💾 Создать бэкап служб

Курсоры не применяются

  • Убедитесь, что в архиве есть .cur / .ani
  • Проверьте папку C:\Windows\Cursors\<name>\
  • Попробуйте «▶️ Применить» ещё раз
  • Сбросьте всё через «🗑️ Удалить все»
