ALL TWEAKER 6 → ANTON VAMPIRE

Один файл All.Tweaker.py на Python + tkinter с жестко заданным словарем tabs.py — и полностью переписанное Electron-приложение на 25+ модулях с 13 вкладками, 100+ темами, 8 CSS-стилями, VampireOS, игровым режимом 2.0 и менеджером служб. В версии 1.2.1 — новые обои, 11 новых твиков VampireOS, а также обновленный логотип и смена темы по умолчанию.

All Tweaker 6
Beta · Python 3 · tkinter + ttkbootstrap
  • Python 3 в PATH (установка через update.bat)
  • PyInstaller / bat-скрипты для запуска
  • All.Tweaker.py (~300 строк) + tabs.py (словарь)
  • Все твики — жестко заданный словарь tabs
  • configparser · settings.ini · Windows-1251
  • ttkbootstrap темы (darkly и др.) + один шрифт
  • Фича «Создать конфиг» → пишет .bat в папку Configs/
  • subprocess.call без патчинга (вызов .bat, .reg через PowerRun.exe)
  • Запуск .ps1 через launcher.exe
  • Обновление через update.bat (busybox wget)
  • 17 вкладок, ~700 твиков
➜
Anton Vampire
v1.2.1 · Electron 44 · Node.js
  • Никаких внешних зависимостей — всё в бандле (Electron + Node.js)
  • electron-builder → NSIS installer
  • 25+ модулей по 100–600 строк (src/main/, src/renderer/)
  • Внешние JSON-источники твиков (динамическая загрузка)
  • JSON · settings.json · UTF-8 · debounce 250 мс
  • 100+ тем в 12 группах + 8 CSS-стилей
  • Новый логотип и смена темы по умолчанию на vampire_the_masquerade (1.2.0-beta)
  • 7 режимов запуска + патчинг .bat + nsudolg/minsudo
  • Бэкап служб, fallback Start=3
  • Обновления через GitHub Releases
  • 13 вкладок, 1000+ твиков
  • Новые обои и 11 новых твиков VampireOS в 1.2.1
